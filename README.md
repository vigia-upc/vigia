# Vigía

App móvil de reporte anónimo de extorsión para comerciantes y bodegueros de Lima.

Proyecto del curso 1ASI0385, UPC.

## Funcionalidades

- Reporte anónimo en menos de 30 segundos, sin datos personales
- Mapa de calor por zona
- Alertas y comunidad
- Dashboard para asociaciones y gremios
